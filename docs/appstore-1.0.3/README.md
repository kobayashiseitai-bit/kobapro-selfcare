# iOS 1.0.3（ビルド10）App Store 提出用の文章（2026-10-03）

- 1.0.2 の説明文は配信中のため書き換えられず、7日間無料・新しい無料の範囲に合わせるために 1.0.3 を作った（ネイティブのコードは 1.0.2 と同じ。版番号だけ上げた）。
- App Store Connect の 1.0.3 に、プロモーション用テキスト・概要・このバージョンの最新情報・審査メモを入力して保存済み。
- 1.0.2 から直したこと：3日間→7日間、無料の範囲（新規は体調チェックだけ）、家族プランの「お互いの記録を共有」（誤り）、写真とデータの扱い（プライバシーポリシーと同じ内容に）、自動更新の説明（ガイドライン 3.1.2）、確かめられない「姫路で」を削除、審査メモの手順の画面の文言（「デバイス引継ぎ（機種変更）」→「コードを入力して復元」）。
- **審査に出す前に**：Vercel production の環境変数 `REVIEWER_USER_IDS` に審査用の user_id（docs/app-review-2026-09.md）を入れて再デプロイすること。入れないと REVIEW26 で入っても有料機能が開かず、審査メモと食い違う。審査が終わったら外す。
