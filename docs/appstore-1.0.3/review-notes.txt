【このアプリについて】
本アプリは医療アプリではなく、セルフケア支援アプリです。
AIによる姿勢チェック・アドバイスは参考情報として提供しており、診断・治療を目的としていません。

【ログインについて】
本アプリにはユーザー名とパスワードによるログインがありません。
アプリを起動し、名前と年齢を入力するだけで、すぐにご利用いただけます。
そのためデモアカウントのIDとパスワードはご用意していません。

【AI機能の確認方法】
AIチャット、AI姿勢チェック、AI食事分析、30日コーチングは有料プランの機能です（体調チェックは無料）。
審査用に、課金なしで全機能をご確認いただけるアカウントを用意しました。
次の手順でお試しください。

1. アプリを起動し、名前と年齢を入力して登録を完了します
2. 画面下の右はしの「メニュー」を押し、「設定」を開きます
3. 「デバイス引継ぎ（機種変更）」の「コードを入力して復元」を選びます
4. 次のコードを入力します

   コード: REVIEW26

5. 復元が完了すると、AI機能がすべて無制限でご利用いただけます

このコードは何度でもご利用いただけます。有効期限は2027年12月31日です。

【アカウント削除の確認について】
審査用のアカウント（コード REVIEW26）は、次回以降の審査でも使えるように、アプリから削除できないようにしています。削除の動作は、アプリを入れ直してから新しく登録したアカウントでお試しください（メニュー → 設定 → アカウントを削除 → 「DELETE」と入力）。
The shared review account (transfer code REVIEW26) cannot be deleted, so that it stays available for future reviews. To test account deletion, please reinstall the app (or use another device), register a new account by entering any name, and delete it from メニュー (Menu) > 設定 (Settings) > アカウントを削除 (Delete account), then type DELETE.

【通常の購入フローを確認される場合】
Sandboxアカウントでの購入もお試しいただけます。
はじめての方は、有料プランのお申し込み時に7日間の無料体験が付き、その後は自動で有料プランに切り替わります。

【カメラの使用について】
姿勢チェックでは全身の写真を2枚撮影します。
実際の人物が写っていなくても動作しますが、人物が画面に入ると骨格の検出が始まります。
撮影を省略される場合は、AIチャットと食事分析だけでも機能をご確認いただけます。

【写真の扱い】
姿勢の読み取りは端末の中で行い、カメラの映像は送信しません。
保存した写真は非公開の保管場所に保存し、食事の分析とAIへの相談のときだけ、AIの会社（Anthropic）へ送ります。AIの学習には使われません。
