## データ安全性の申告について（Google Play）

現行の「第三者と共有するデータはありません」は**そのままで問題ない**。
AI解析のためのAPI送信は個人情報保護法上の「委託」にあたり、第三者提供ではないため。
Google の Data Safety も、開発者の指示で処理するサービスプロバイダへの送信は「共有」から除外している。

変更が必要なのは説明文の言い回しだけ。
旧文の「撮影した写真は外部に共有されません」は、法的には正しくても
一般の読み手には「写真は端末から出ない」と読めてしまうため、上記の新文面に差し替える。
