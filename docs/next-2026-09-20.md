# 明日（2026-09-20）朝いちの作業メモ

## 1. 最優先：ブラウザから無料で有料プランになれる穴をふさぐ

**何が起きているか。** `https://posture-app-steel.vercel.app` をパソコンのブラウザで開くと、
カード登録をしなくても有料プランになれてしまう。実際に検証して再現済み（検証用アカウントは削除済み）。

**原因。** `src/app/api/subscription/route.ts` の `action === "subscribe"` が、
支払いを確認せずに `status` を `active_monthly` / `active_yearly` に書き換えている。
アプリ内（iOS/Android）はストアの課金を通るが、ブラウザにはストア課金が無いため、
この処理だけがむき出しで残っている。

**直し方。** ブラウザから来た `subscribe` は課金を有効にせず、
「アプリからお申し込みください」を返す。審査は不要（Vercel のデプロイだけ）。
