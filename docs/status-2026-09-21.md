## 終わったこと

**課金まわりの穴を3つふさいだ**

1. **ブラウザから支払いなしで有料プランになれた**（9/20 修正）
   `/api/subscription` の subscribe / start_trial が、ストアの購入を確認せずに
   status を書き換えていた。ブラウザで実際に再現して確認済み。
   → 両アクションを削除。本番で403を確認。

2. **「解約する」を押しても請求が止まらなかった**（9/21 修正）
   このアプリのDBだけ cancelled にしており、ストアの定期購入は生きたままだった。
   → ボタンを廃止し、App Store / Google Play の管理画面への案内に変更。
   トライアル中の方にも表示するようにした。
   あわせて `/api/subscription` の POST を全廃（本番で405を確認）。

3. **課金状態が一度読まれると更新されなかった**（9/21 修正）
   Next.js が supabase-js の select（GET）をキャッシュしており、
   DBを変えてもAPIが古い値を返し続けていた。`x-vercel-cache` は MISS なので
   CDNではなく内側のキャッシュ。
   → 購入が Webhook で記録されても「無料プラン」のままになりうる状態だった。
   `src/app/lib/supabase-server.ts` を追加し、API 28本すべてを no-store に統一。
   本番で「DBを変える→APIが即追随する」ことを確認済み。
